🎮 두 대 PC 실행 가이드
1단계: 두 PC 모두 같은 와이파이 연결
같은 공유기 / 같은 와이파이 SSID 필수
모바일 핫스팟도 가능
2단계: 두 PC 모두 게임 실행
이클립스에서 TetrisMain.main() 실행 → 홈 화면 → ONLINE MULTI 클릭

3단계: 한 명은 호스트, 한 명은 게스트
🏠 PC A (호스트):

로비 화면 상단의 내 IP: XXX.XXX.X.X 확인 (예: 192.168.0.10)
"방 만들기 (호스트)" 클릭
"게스트 접속을 기다리는 중..." 메시지 표시 → 대기
🚪 PC B (게스트):

상대 IP 입력란에 PC A의 IP 입력 (예: 192.168.0.10)
"방 참가하기 (게스트)" 클릭
접속되면 자동으로 게임 시작 🎉
⚠️ 윈도우 방화벽 설정 (호스트 PC)
처음 실행하면 방화벽 알림 창이 뜰 수 있어요:

"Java(TM) Platform SE binary의 네트워크 액세스 허용"
→ "전용 네트워크" 체크 → 허용
이미 거부하신 경우:

제어판 → Windows Defender 방화벽 → 앱 또는 기능 허용
→ Java 항목에 "전용 네트워크" 체크
🔧 문제 해결
증상	원인 / 해결
"접속 실패"	IP 오타 / 방화벽 차단 / 다른 와이파이
한쪽이 멈춤	연결 끊김 → ESC로 종료 후 재시작
IP가 127.0.0.1로 나옴	와이파이 연결 안 됨 / VPN 켜져있음
게임은 되는데 상대 보드가 안 보임	정상 (잠시 후 동기화됨)
📋 게임 정보
조작 (둘 다 동일):

A/D = 이동, W = 회전, S = 소프트 드롭, Space = 하드 드롭, Q = 홀드
ESC = 종료
공격 규칙:

2줄+ 클리어 시 (줄-1) 만큼 상대에게 공격
최대 4줄, T-스핀은 2배
공격은 2초 후에 적용 (반격 가능)
좌측 보드 = 나, 우측 보드 = 상대

상대 보드는 20Hz로 실시간 동기화 (약 50ms마다)
공격은 즉시 전송
